# Furniture & Landscapes

A self-contained responsive HTML and CSS class project by Jacob Bernard. It combines a full-screen video introduction with an image-led collection of outdoor furniture and landscaping concepts.

## Run locally

Open `index.html` directly, or serve this directory with any static file server.

## Deployment

This project is configured as a static site and can be deployed directly to Vercel with no build command.

The registration screen is a visual prototype. It does not collect, store, or transmit submitted information.
